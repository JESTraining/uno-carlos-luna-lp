## Phase 1: Architecture Foundation (CRITICAL)

### Course
**[Software Architecture & Design of Modern Large Scale Systems](https://www.udemy.com/course/software-architecture-design-of-modern-large-scale-systems/)** 

**Instructor:** Michael Pogrebinsky (Google, Intel alumni, iSAQB-certified trainer) 

**Duration:** 8 hours | **Last Updated:** December 2025 

### Why This Course for Carlos

Carlos scored **33% in Architecture** – this is a career-limiting gap for a senior developer. He knows "basics of Microservices" but cannot design them. This course directly addresses:

| Carlos's Weakness | How This Course Fixes It |
| :--- | :--- |
| Knows "basics of communication among microservices" (33%) | Full modules on **architectural building blocks** and **API design** for large-scale systems  |
| Knows "basics of Message Brokers" (33%) | Covers **event-stream processing** and **Big Data architecture patterns**  |
| "Some experience with SOLID" but not application | Teaches **industry-proven patterns** and **trade-offs** like a true architect  |
| No mention of scalability concepts | Dedicated section on **High Scalability, Availability, and Performance**  |

### What Carlos Will Learn

- How to identify technical requirements without missing details
- How to define robust, easy-to-use APIs
- How to apply modern building blocks for systems handling millions of requests/day
- How to think in trade-offs like a professional software architect 

> **Note:** This course contains **no coding** – it is pure design and architecture, exactly what Carlos needs. Coding is implementation; Carlos needs to learn design first.

## Phase 2: Performance Deep Dive (HIGH)

### Course
**[C# Performance Tricks: How To Radically Speed Up Your Code](https://www.udemy.com/course/csharp-performance-tricks-how-to-radically-optimize-your-code/)** 

**Instructor:** Nick Chapsas | **Duration:** 4.5 hours | **Last Updated:** May 2024 

### Why This Course for Carlos

Carlos scored **55.6% in Performance** – his assessment explicitly says he knows "basics" of GC, async vs parallel, and IEnumerable vs IQueryable. This course eliminates those gaps:

| Carlos's Exact Gap | How This Course Fixes It |
| :--- | :--- |
| "Knows the basics of Garbage Collector" (55%) | Deep dive into **GC assumptions about object size and lifetime**  |
| "Knows the basics of difference between async and parallel" (55%) | Complete coverage of **when to use each** with benchmarks |
| "Knows the basics of Async Programming" (55%) | Practical async optimization patterns |
| "Some experience with differences between IEnumerable and IQueryable" (55%) | **CIL (Common Intermediate Language)** crash course to understand what actually happens  |
| Not mentioned: string performance, exceptions, boxing | Covers **stringbuilder vs concatenation (200x difference)** and **exception handling (1000x slower)**  |

### What Carlos Will Learn

- Why the wrong string approach slows code by **200x**
- Why bad exception handling slows code by **1000x**
- How to read CIL to identify performance traps
- When to use pointers in C# (and when not to)
- Super-fast object construction techniques 

> **Key differentiator:** Most C# courses teach *how* to write code. This course teaches *how to write fast code* – a senior-level distinction.

### Course
**[Docker & Kubernetes: The Practical Guide](https://www.udemy.com/course/docker-kubernetes-the-practical-guide/)** 

**Instructor:** Maximilian Schwarzmüller (Academind, 3.5M+ students) 

**Duration:** 24 hours | **Last Updated:** January 2026 

### Why This Course for Carlos

Carlos's Architecture score (33%) shows he knows "basics of microservices" but cannot implement or deploy them. This course bridges the gap between design and real-world deployment:

| Carlos's Gap | How This Course Fixes It |
| :--- | :--- |
| "Knows basics of communication among microservices" | **Container networking** and **DNS service discovery** for microservice communication  |
| No container knowledge assessed | Complete Docker fundamentals: images, containers, volumes |
| No orchestration knowledge | Full Kubernetes section: deployments, services, scaling |
| No deployment experience | **AWS ECS** and **EKS** deployment modules  |

### What Carlos Will Learn

- How to deploy to AWS (ECS and EKS) 

> **Value for Carlos:** This course transforms his theoretical "basics of microservices" (33%) into practical, deployable skills that senior .NET developers in Mexico must have.
